# LACTISVALLE

## Anexo A – Catálogo de necesidades e historias de usuario

### 1. Introducción

Este anexo presenta las principales necesidades identificadas para el sistema **LactisValle** y las historias de usuario planteadas para representar las funciones que debe cumplir la solución tecnológica.

Las historias de usuario permiten expresar los requerimientos desde la perspectiva de las personas que utilizarán el sistema.

---

## 2. Catálogo de necesidades

| ID | Necesidad | Descripción |
|---|---|---|
| N01 | Registro de usuarios | Permitir registrar y gestionar los usuarios que tendrán acceso al sistema. |
| N02 | Registro de fincas | Contar con información organizada de las fincas vinculadas al proceso productivo. |
| N03 | Registro de bovinos | Registrar y consultar la información básica de los bovinos pertenecientes a cada finca. |
| N04 | Registro de pesajes | Registrar el peso de los bovinos y conservar un historial de los datos obtenidos. |
| N05 | Funcionamiento sin conexión | Permitir registrar información cuando no exista conexión a Internet y sincronizarla posteriormente. |
| N06 | Consulta de información | Facilitar la consulta de los registros almacenados en el sistema. |
| N07 | Organización de los datos | Mantener la información estructurada para facilitar su administración y consulta. |
| N08 | Control de registros | Mantener un historial de los registros realizados para apoyar el seguimiento del proceso productivo. |

---

## 3. Historias de usuario

| ID | Historia de usuario | Criterio de aceptación |
|---|---|---|
| HU01 | Como usuario, quiero registrarme en el sistema para poder acceder a las funciones de LactisValle. | El sistema debe permitir registrar los datos necesarios del usuario y validar la información. |
| HU02 | Como usuario, quiero registrar una finca para poder organizar la información de la unidad productiva. | El sistema debe permitir crear y consultar los datos correspondientes a una finca. |
| HU03 | Como usuario, quiero registrar un bovino para poder identificar y llevar control de cada animal. | El sistema debe permitir guardar la información básica de cada bovino. |
| HU04 | Como usuario, quiero registrar el peso de un bovino para poder realizar seguimiento de su crecimiento. | El sistema debe permitir guardar el peso asociado al bovino y la fecha del registro. |
| HU05 | Como usuario, quiero utilizar el sistema sin conexión a Internet para poder registrar información en zonas con poca conectividad. | El sistema debe permitir almacenar temporalmente los registros cuando no haya conexión. |
| HU06 | Como usuario, quiero que los datos se sincronicen cuando exista conexión para mantener actualizada la información. | Los registros pendientes deben sincronizarse cuando vuelva a existir conexión. |
| HU07 | Como usuario, quiero consultar el historial de pesajes para conocer la evolución de los bovinos. | El sistema debe mostrar los registros históricos asociados a cada bovino. |
| HU08 | Como usuario, quiero consultar la información organizada para facilitar el seguimiento de la producción. | El sistema debe presentar la información de manera clara y organizada para su consulta. |

---

## 4. Observación

Las necesidades e historias de usuario presentadas permiten establecer una base para el desarrollo de LactisValle, teniendo en cuenta las condiciones de conectividad y las actividades relacionadas con el registro y seguimiento de los bovinos.
