ANEXO B. REGISTRO DE DECISIONES DE ARQUITECTURA (ADR SIMPLIFICADO)

Este registro presenta las principales decisiones técnicas consideradas para orientar el desarrollo de LactisValle, teniendo en cuenta las condiciones del entorno rural y la conectividad intermitente.

ADR-01 — Uso de arquitectura Offline First

Contexto: La conexión a Internet puede ser inestable o inexistente durante el ordeño.

Alternativas: conexión permanente; almacenamiento local con sincronización posterior; equipos especializados.

Decisión: utilizar una arquitectura Offline First.

Razón: permite continuar con el registro durante los periodos sin conectividad y sincronizar posteriormente la información.

ADR-02 — Uso de una PWA

Contexto: LactisValle debe utilizarse desde dispositivos móviles durante las actividades de ordeño.

Alternativas: aplicación móvil nativa; aplicación web tradicional; Progressive Web App.

Decisión: utilizar una Progressive Web App (PWA).

Razón: facilita el uso desde dispositivos móviles y permite orientar la aplicación al funcionamiento sin conexión.

ADR-03 — Uso de IndexedDB para almacenamiento local

Contexto: los pesajes deben conservarse en el dispositivo cuando no exista conexión.

Alternativas: no almacenar hasta recuperar Internet; almacenamiento local básico; IndexedDB.

Decisión: utilizar IndexedDB para almacenar localmente la información necesaria.

Razón: permite mantener información estructurada en el dispositivo y manejar registros pendientes de sincronización.

ADR-04 — Uso de una cola FIFO

Contexto: pueden existir varios pesajes pendientes cuando se recupere la conexión.

Alternativas: envío sin orden; enviar solo el último registro; cola FIFO.

Decisión: utilizar una cola FIFO (First-In, First-Out).

Razón: permite procesar los registros siguiendo el orden en que fueron capturados.

ADR-05 — Modelo de datos basado en entidades relacionadas

Contexto: el sistema debe relacionar fincas, usuarios, bovinos y registros de pesaje.

Alternativas: una estructura única; entidades separadas y relacionadas.

Decisión: utilizar las entidades Finca, Usuario, Bovino y Registro de Pesaje.

Razón: esta estructura permite organizar la información y establecer las relaciones necesarias para el control de la producción.
