ANEXO C. PRESUPUESTO DEL PROYECTO LACTISVALLE

Para el desarrollo de LactisValle se identificaron los principales recursos necesarios para llevar a cabo las diferentes etapas del proyecto. En esta fase se presenta la relación de recursos, sin establecer valores económicos definitivos, debido a que el proyecto todavía se encuentra en desarrollo.

RecursoDescripción
Equipo de desarrolloComputador utilizado para la programación, diseño, pruebas y documentación del proyecto.
Dispositivo móvilTeléfono utilizado para probar el funcionamiento de la PWA y el registro de información en campo.
Servicio de InternetConectividad necesaria para el desarrollo, pruebas y posterior sincronización de los datos con el servidor.
Servidor / alojamientoRecurso necesario para alojar la API y la base de datos central en las etapas posteriores.
DominioRecurso previsto para una posible publicación del sistema en Internet.
Herramientas de softwareHerramientas necesarias para desarrollar, probar y mantener la aplicación.
Transporte para validaciónRecurso previsto para los desplazamientos relacionados con entrevistas y pruebas de usabilidad en campo.

Observación: La estimación económica definitiva se podrá establecer en las siguientes etapas del proyecto, de acuerdo con las necesidades reales de implementación, los recursos disponibles y las características del servidor y demás servicios que finalmente sean utilizados.
